The pattern, in three lines

Each of the 100 ships as an IDomain (POC Phase 2+). Each domain declares its neurons (user-verbs) as INeuron<T> handlers. At install, a tiny manifest maps verbs to persona mimes:

  • Verb — a canonical synapse type (e.g. Uber.Contracts.CallRide)
  • Mime — a symbol from the ~15-gesture shared vocabulary (e.g. reach_phone) that the persona already knows how to play
  • Notification hook — opt-in, status-stream fires StatusChanged to the system Notifier neuron, which surfaces native iOS/Android banners

New domain installed ⇒ persona already knows how to express its neurons (verbs). No new animations to ship. Claude can author the manifest when Claude authors the domain — one prompt, done.
