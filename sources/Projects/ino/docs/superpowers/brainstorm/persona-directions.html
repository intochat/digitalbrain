On the architecture
of a living persona.

Three directions, three live engines running in parallel. Press any signal on the bus below and all three columns receive it at the same instant — each reacts on its own terms. The point is to feel the difference, not to read about it.

The orb
has a pulse.

Push stream replaces the 3-second poll. Every signal snaps the target values; the orb lerps toward it in ~150 ms. When input stops, the target resets to idle. No memory, no continuity — pure reactivity.

The persona
has a brain.

Durable grain holds a list of synapses, each decaying on its own half-life. The brain state is a weighted blend of surviving signals. Silence lets moods fade. Bursts accumulate. Continuity is free.

C

Personas are
primitives you fork.

Same brain model as B, but each persona is a neuron with a Shape(signal) function that re-weights inputs before they hit its brain. Three personalities, one signal stream — the same event produces three reactions. Users fork their own.

Watch the three orbs react to the same signal. Jarvis barely moves. Luna swells dramatically. Coach pulses aggressively. The difference is not the signal — it's the neuron in front of the brain.
