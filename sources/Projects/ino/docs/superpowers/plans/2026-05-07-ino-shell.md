# ino-shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a new Flutter `/shell` route that ports the Claude-Design ino-shell prototype, validates the neuron+synapse abstractions visually, and runs a fully-mocked Tokyo storyboard sourced from a Reqnroll feature file.

**Architecture:** `/shell` lives alongside `/brain` (no rip-out). It uses `three_js` for the brain canvas (sphere of clusters + comet synapses), the existing Rive `persona_orb.riv` for the persona, and the existing BLoC layer. A Reqnroll feature in `Ino.Domains.Travel.Tests` is the single source of truth — it doubles as a behavioural test (asserts cluster firings) and emits `tokyo.json` consumed by Flutter's `DemoRunner`.

**Tech Stack:**
- Flutter 3.41 (web · CanvasKit), Dart 3.11, `three_js ^0.3.0`, `rive ^0.14.5`, `flutter_bloc ^9.1.1`, `go_router ^17.2.0`
- .NET 11, Reqnroll (latest stable on nuget — verify via Context7), xUnit v3, Orleans 10
- The ino kernel silo serves the Flutter app from `Ino.Kernel/wwwroot/` after `dotnet build` runs the `flutter build web` target

**Spec:** `docs/superpowers/specs/2026-05-07-ino-shell-design.md`. Read it before starting any task — task descriptions assume familiarity.

**Source design (reference, do NOT copy-paste verbatim):** `docs/ino-design/ino-shell.html` and `docs/ino-design/src/{data,brain,inspector,demo,cards,orb,timeline,main}.js`.

import 'package:flutter/material.dart';

/// Static topology shared by the brain canvas, demo runner, and inspector.
/// Sourced verbatim from `docs/ino-design/src/data.js` (CLUSTERS + ALIAS).
class ShellCluster {
  const ShellCluster({
    required this.id,
    required this.label,
    required this.domain,
    required this.position,
    required this.color,
    required this.size,
    required this.aliases,
  });

  final String id;
  final String label;
  final String domain;
  final ({double x, double y, double z}) position;
  final Color color;
  final double size;
  final List<String> aliases;
}

class ShellNeuron {
  const ShellNeuron({
    required this.id,
    required this.alias,
    required this.cluster,
    required this.domain,
    required this.color,
  });

  final String id;
  final String alias;
  final String cluster;
  final String domain;
  final Color color;
}

// domains/travel/Ino.Domains.Travel.Tests/Storyboard/StoryboardRecorder.cs
using System.Text.Json;
using System.Text.Json.Nodes;

namespace Ino.Domains.Travel.Tests.Storyboard;

public sealed class StoryboardRecorder
{
    private readonly List<StoryboardEvent> _events = new();

    public StoryboardRecorder(string id, string label)
    {
        Id = id;
        Label = label;
    }

    public string Id { get; }
    public string Label { get; }
    public IReadOnlyList<StoryboardEvent> Events => _events;
    public double DurationSeconds => _events.Count == 0 ? 0 : _events[^1].T + 0.4;

    public void AppendOrb(double t, string state)
        => _events.Add(new OrbEvent(t, state));
    public void AppendUtter(double t, string text)
        => _events.Add(new UtterEvent(t, text));
    public void AppendSynapse(double t, string from, string to, JsonElement payload, bool gold)
        => _events.Add(new SynapseEvent(t, from, to, payload, gold));
    public void AppendCard(double t, string id, string stage, string? fromCluster)
        => _events.Add(new CardEvent(t, id, stage, fromCluster));

    public string ToJson()
    {
        var root = new JsonObject
        {
            ["id"] = Id,
            ["label"] = Label,
            ["duration_s"] = DurationSeconds,
            ["events"] = new JsonArray(_events.Select(SerializeEvent).ToArray()),
        };
        return root.ToJsonString(new JsonSerializerOptions { WriteIndented = true });
    }

    private static JsonNode SerializeEvent(StoryboardEvent e) => e switch
    {
        OrbEvent o => new JsonObject
        {
            ["t"] = o.T, ["kind"] = "orb", ["state"] = o.State,
        },
        UtterEvent u => new JsonObject
        {
            ["t"] = u.T, ["kind"] = "utter", ["text"] = u.Text,
        },
        SynapseEvent s => new JsonObject
        {
            ["t"] = s.T, ["kind"] = "syn",
            ["from"] = s.From, ["to"] = s.To,
            ["payload"] = JsonNode.Parse(s.Payload.GetRawText()),
            ["gold"] = s.Gold,
        },
        CardEvent c => new JsonObject
        {
            ["t"] = c.T, ["kind"] = "card",
            ["id"] = c.Id, ["stage"] = c.Stage,
            ["from"] = c.FromCluster,
        },
        _ => throw new InvalidOperationException($"Unknown event {e.GetType()}"),
    };
}

// clients/ino.flutter/lib/screens/shell/shell_brain_canvas.dart
import 'dart:math' as math;
import 'package:flutter/material.dart';
import 'package:three_js/three_js.dart' as three;
import 'shell_brain_topology.dart';

const double _sphereR = 1.55;

class ShellBrainCanvas extends StatefulWidget {
  const ShellBrainCanvas({super.key});

  @override
  State<ShellBrainCanvas> createState() => ShellBrainCanvasState();
}

class ShellBrainCanvasState extends State<ShellBrainCanvas> {
  late three.ThreeJS _three;
  final List<three.Mesh> _neuronMeshes = [];
  final List<three.Mesh> _haloMeshes = [];

  @override
  void initState() {
    super.initState();
    _three = three.ThreeJS(
      onSetupComplete: () => setState(() {}),
      setup: _setup,
      settings: three.Settings(antialias: true),
    );
  }

  Future<void> _setup() async {
    _three.scene = three.Scene();
    _three.camera = three.PerspectiveCamera(
      45, _three.width / _three.height, 0.01, 100,
    )..position.setValues(0, 0.2, 4.5);

    _placeNeurons();
    _three.addAnimationEvent(_animate);
  }

  void _placeNeurons() {
    final rand = math.Random(42); // deterministic jitter
    for (final n in ShellTopology.neurons) {
      final c = ShellTopology.clusters.firstWhere((cc) => cc.id == n.cluster);
      final centerVec = three.Vector3(c.position.x, c.position.y, c.position.z)
        ..normalize().scale(_sphereR);
      final jitter = three.Vector3(
        (rand.nextDouble() - 0.5) * 0.45,
        (rand.nextDouble() - 0.5) * 0.45,
        (rand.nextDouble() - 0.5) * 0.45,
      );
      final pos = centerVec.clone().add(jitter)
        ..normalize().scale(_sphereR + (rand.nextDouble() - 0.5) * 0.18);

      final size = 0.03 + rand.nextDouble() * 0.025;
      final geo = three.SphereGeometry(size, 18, 18);
      final mat = three.MeshBasicMaterial.fromMap({
        'color': c.color.value & 0x00FFFFFF,
        'transparent': true,
        'opacity': 0.85,
      });
      final mesh = three.Mesh(geo, mat)..position.copy(pos);
      mesh.userData['neuronAlias'] = n.alias;
      mesh.userData['baseSize'] = size;
      mesh.userData['baseOpacity'] = 0.78;
      mesh.userData['flare'] = 0.0;
      _three.scene.add(mesh);
      _neuronMeshes.add(mesh);

      final haloMat = three.MeshBasicMaterial.fromMap({
        'color': c.color.value & 0x00FFFFFF,
        'transparent': true,
        'opacity': 0.0,
        'depthWrite': false,
        'blending': three.AdditiveBlending,
      });
      final halo = three.Mesh(three.SphereGeometry(size * 3.2, 18, 18), haloMat)
        ..position.copy(pos);
      _three.scene.add(halo);
      _haloMeshes.add(halo);
    }
  }

  void _animate(double dt) {
    final t = (_three.clock.elapsedTime).toDouble();
    for (var i = 0; i < _neuronMeshes.length; i++) {
      final m = _neuronMeshes[i];
      final flare = (m.userData['flare'] as double);
      final pulse = 1 + 0.06 * math.sin(t * 1.2 + i * 0.7);
      var scale = pulse;
      var opacity = m.userData['baseOpacity'] as double;
      if (flare > 0) {
        final next = math.max(0, flare - dt * 1.6);
        m.userData['flare'] = next;
        scale += flare * 1.6;

  if (fromN == null || toN == null) return null;

  final tailGeo = three.BufferGeometry().setFromPoints(curve.getPoints(50));
  final tailMat = three.LineBasicMaterial.fromMap({
    'color': color, 'transparent': true, 'opacity': 0.12,
    'blending': three.AdditiveBlending,
  });
  final tail = three.Line(tailGeo, tailMat);
  _three.scene.add(tail);

  final headMat = three.MeshBasicMaterial.fromMap({
    'color': color, 'transparent': true, 'opacity': 1,
    'blending': three.AdditiveBlending,
  });
  final head = three.Mesh(three.SphereGeometry(0.04, 14, 14), headMat)
    ..position.copy(a);
  _three.scene.add(head);

  final haloMat = three.MeshBasicMaterial.fromMap({
    'color': color, 'transparent': true, 'opacity': 0.35,
    'blending': three.AdditiveBlending, 'depthWrite': false,
  });
  final halo = three.Mesh(three.SphereGeometry(0.13, 18, 18), haloMat);
  head.add(halo);

  // Side effects
  flareNeuron(from, 1);
  Future.delayed(Duration(milliseconds: (dur * 700).round()),
      () { if (mounted) flareNeuron(to, 1); });
  fireCluster(fromN.cluster, 0.6);
  Future.delayed(Duration(milliseconds: (dur * 700).round()),
      () { if (mounted) fireCluster(toN.cluster, 1.0); });

  final syn = _ActiveSynapse(
    head: head, tail: tail, halo: halo, curve: curve,
    dur: dur, from: from, to: to, payload: payload, gold: gold,

## Milestone 10 — DemoRunner

### Task 10.1: DemoRunner reads tokyo.json + dispatches events

**Files:**
- Create: `clients/ino.flutter/lib/screens/shell/demo_runner.dart`
- Test: `clients/ino.flutter/test/shell/demo_runner_test.dart`

- [ ] **Step 1: Implement DemoRunner with fake clock for tests**

```dart
class DemoRunner {
  DemoRunner(this._refs, {Clock? clock}) : _clock = clock ?? const Clock();

  final ShellRefs _refs;
  final Clock _clock;
  final List<Timer> _timers = [];

  Future<Storyboard> _load(String id) async {
    final raw = await rootBundle.loadString('assets/storyboards/$id.json');
    return Storyboard.fromJson(jsonDecode(raw));
  }

  Future<void> play([String id = 'tokyo']) async {
    stop();
    final sb = await _load(id);
    for (final ev in sb.events) {
      _timers.add(Timer(Duration(milliseconds: (ev.t * 1000).round()),
          () => _dispatch(ev)));
    }
  }

  void _dispatch(StoryboardEvent ev) {
    switch (ev) {
      case OrbEvent o: _refs.persona.add(PersonaEmotionChanged(_mapOrb(o.state)));
      case SynapseEvent s: _refs.canvas.spawnSynapse(
          from: s.from, to: s.to, payload: s.payload, gold: s.gold);
      case CardEvent c when c.stage == 'enter':
        _refs.compose.showCard(c.id, fromCluster: c.fromCluster);
      case CardEvent c when c.stage == 'morph':
        _refs.compose.morphCard(c.id);
      case UtterEvent u: _refs.input.text = u.text;
    }
  }

  void replan() => play('tokyo-replan');
  void stop() { for (final t in _timers) t.cancel(); _timers.clear(); }
}
```

`ShellRefs` is a small DTO holding refs to PersonaBloc, ShellBrainCanvasState, ShellComposeState, and the input controller.
