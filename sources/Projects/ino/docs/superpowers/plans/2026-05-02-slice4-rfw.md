# Slice 4 — RFW (Remote Flutter Widgets) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Travel plans return server-authored UI — flight cards, hotel cards, place cards rendered by the Flutter client from RFW DSL — instead of plain text. Tap "Select" on a flight card → fires a callback synapse → next plan step (hotel) emits a fresh RFW tree.

**Architecture:** Four sub-commits, sequential. (4A) `RfwPayload` contract + upgrade `NeuronResult.Rfw` byte field to a structured record + wire ChatService server-side serialization with CRLF strip. (4B) Travel plans (FindFlights, PlanTrip) emit RFW payloads with mock data. (4C) Flutter `pubspec` adds `rfw`, custom widget library defines FlightCard / HotelCard / PlaceCard, chat_bubble branches on RFW. (4D) New `RfwEvent` gRPC RPC + `CorrelationRegistry` grain + plan-side `IRfwEventHandler` interface for two-way callbacks.

**Tech Stack:** `package:rfw` (Flutter), Orleans 10, gRPC + protobuf (`google.protobuf.Struct`), C# 13.

**Spec reference:** `docs/superpowers/specs/2026-05-02-phase4-epilogue-design.md` § Slice 4.

**Largest slice by ~5×.** Budget 3–5 days. **STOP and reconvene with the user if R1 (security research) reveals a showstopper.**

```csharp
// RFW parser pre-1.x rejected Windows CRLF — strip server-side as a safety net.
// Verified against package:rfw <version> in docs/rfw-research-notes.md.
private static byte[] StripCr(byte[] input)
{
    var dst = new byte[input.Length];
    int j = 0;
    for (int i = 0; i < input.Length; i++)
    {
        if (input[i] != (byte)'\r') dst[j++] = input[i];
    }
    return j == input.Length ? input : dst[..j];
}
```

If R2 confirmed CRLF is fine in the current `package:rfw`: skip the StripCr helper and assign the byte arrays directly.

## Task 7 — `FlightCardListBuilder`

**Files:**
- Create: `domains/travel/Ino.Domains.Travel/Rfw/FlightCardListBuilder.cs`

- [ ] **Step 1: Write the builder**

```csharp
using System.Text;
using System.Text.Json;
using Ino.Core;

namespace Ino.Domains.Travel.Rfw;

internal static class FlightCardListBuilder
{
    public static RfwPayload Build(IReadOnlyList<FlightOption> flights)
    {
        // DSL syntax verified against docs/rfw-research-notes.md (R3).
        // The `event 'flight.selected' { flightId: ... }` form sends an event
        // back to the Dart host's Runtime.eventStream when the card is tapped.
        var dsl = new StringBuilder();
        dsl.AppendLine("import widgets;");
        dsl.AppendLine("import ino.travel;");
        dsl.AppendLine();
        dsl.AppendLine("widget root = Column(");
        dsl.AppendLine("  children: [");
        dsl.AppendLine("    ...for flight in data.flights: FlightCard(");
        dsl.AppendLine("      airline: flight.airline,");
        dsl.AppendLine("      price: flight.price,");
        dsl.AppendLine("      durationMin: flight.durationMin,");
        dsl.AppendLine("      origin: flight.origin,");
        dsl.AppendLine("      destination: flight.destination,");
        dsl.AppendLine("      flightId: flight.id,");
        dsl.AppendLine("      onSelect: event 'flight.selected' { flightId: flight.id },");
        dsl.AppendLine("    ),");
        dsl.AppendLine("  ],");
        dsl.AppendLine(");");

        var data = new
        {
            flights = flights.Select(f => new
            {
                id = f.Id,
                airline = f.Airline,
                price = (double)f.Price,
                durationMin = f.DurationMin,
                origin = f.Origin,
                destination = f.Destination,
            }).ToArray(),
        };

        return new RfwPayload(
            LibraryName: "ino.travel.flights",
            DescriptionDsl: Encoding.UTF8.GetBytes(dsl.ToString()),
            DataPayload: JsonSerializer.SerializeToUtf8Bytes(data));
    }
}
```

> If R3 returned a different event-binding syntax than `event 'name' { args }`, replace the `onSelect:` line accordingly.

/// Subscribes to a `Runtime.eventStream` and forwards typed events into

class InoRfwEventDispatcher {

        eventName: event.eventName,
        args: Map<String, dynamic>.from(event.eventArguments),

    });
  }
