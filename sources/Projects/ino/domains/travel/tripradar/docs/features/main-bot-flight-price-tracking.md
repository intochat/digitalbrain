# Отслеживать цены на авиаперелеты

## Коротко
Пользователь на главной странице бота нажимает `Flights`, вводит маршрут и даты, получает топ-5 вариантов и включает отслеживание цены.

## Flow
1. Ввод: аэропорт вылета, аэропорт прилета, дата вылета, при необходимости дата возврата.
2. Бот вызывает GraphQL `flights` и получает `bestFlights`, `otherFlights`, `buyUrl`.
3. Бот отправляет:
- топ-5 вариантов,
- цену,
- ссылку на покупку,
- график цены в виде PNG,
- кнопку `Track price`.
4. По кнопке `Track price` бот создает tracking через `POST /api/v1/scheduled-queries/flights`.
5. Дальше бот получает обновления цены из Kafka и отправляет уведомления в Telegram.

## Что важно указать в ТЗ
- точный Kafka topic для flight-уведомлений: `Flights`,
- bot consumer уже подписан на `Flights`, group id: `assistant-telegram-flights`,
- в backend также существуют topics: `Hotels`, `Events`, `LocalPlaces`,
- topic `trip-events` есть в `TripRadar.Silo`, но это отдельный внутренний consumer, не основной topic для Telegram flight alerts.

## Что должен видеть пользователь
- маршрут,
- текущую минимальную цену,
- кнопку запуска трекинга,
- картинку с графиком цены,
- ссылку на покупку.

## Техническое замечание
График не обязан приходить из отдельного сервиса. Для MVP его можно рендерить как обычную картинку PNG, например из React-компонента, и отправлять в Telegram как image.

## Scope
- WebApp пока не фиксируем в обязательный сценарий.
- Главная цель MVP: поиск + запуск трекинга + уведомления из Kafka.
