One brain. Two neuron classes. One turn physics.

Keep Orleans-durable product modules. Port POC’s proof that owner-reviewed ordinary C# becomes normal durable neurons. Delete dual runtimes, dummy scripting, and prototype residue from the mental model (and eventually from the tree).

Target claim: a human programs the brain in ordinary C# (modules) or by approving generated C# candidates; both ride the same journaled turn, outbox, owner scope, and trusted-effect boundary.

Architecture thesis

Keep product physics Orleans Neuron grain · journals · outbox drain · owner session · modules
Port POC seams FireSynapse for candidates · grants · Creator · cold admit · control plane
Do not port POC file RunStore · dual journal · Prototypes InoLang / interpreters
Strongest counterargument: product neurons are grains with capability methods; POC neurons are plain classes hosted by an activation grain. Unifying without an activation adapter re-leaks GrainFactory / IServiceProvider into generated code. Answer: two activation paths, one Deliver/commit/outbox pipeline.

Refactor plan (order is load-bearing)

No module rewrite, no UI churn, no POC deletion until lower layers are clean and the first admission gate is green.

Phase 0 — Architecture lock

output: this page + decision sheet · no code
  • Confirm activation dual-path, FireSynapse-for-candidates, cold admit, Orleans-only durability
  • Name packages for Creator / ControlPlane / Candidates
  • Choose first vertical: chart sample module (POC route) as product integration gate
  • Freeze non-goals: hot load, InoLang, hostile-IL sandbox, dual journal

Phase 1 — Abstractions cleanup

DigitalBrain.Abstractions · tests that pin public surface
  • Inventory every public type; mark keep / thin / delete with a live consumer
  • Keep core vocabulary: Synapse, IHandle, IEmit, INeuron, ids, SynapseDelivery, journal types, IModule
  • Add only admission-facing types that Core will need soon (e.g. grant / family id shapes) — no speculative APIs
  • Delete residual behavior/script types with no consumer; update any wire-compat deliberately
  • Gate: product solution still builds; module contracts recompile without behavior leftovers

Phase 2 — Core refactor + candidate activation

DigitalBrain.Core · the merge heart
  • Document turn law as code: Deliver → exact dispatch → commit journals/outbox → drain
  • Introduce CandidateActivationGrain hosting plain candidate neurons (POC seam)
  • Introduce grant-checked candidate IDigitalBrain proxy (FireSynapse)
  • Immutable route table from verified catalog; runtime-owned envelopes
  • Map POC durable-turn proofs onto Orleans journals (receipt dedupe, outbox pin to revision)
  • Do not import POC RunStore
  • Gate: existing product module tests green; new Core facts for candidate dispatch + grant refuse

Phase 3 — Kernel / Client / Aspire

client entry · silo composition · hosting
  • Align IDigitalBrain docs and implementation with Phase 1–2 surface
  • Kernel composition loads trusted modules + optional admitted candidate assemblies (restart)
  • Aspire resource names stay shared; no second brain process for candidates
  • MCP/Kernel HTTP remain thin; no creator logic in maps
  • Gate: aspire run healthy; chat/MCP smoke still works

Phase 4 — Scripting → Creator rail

replace dummy Scripting with real authoring packages
  • Port Creator (AST-first, fixed header, semantic allowlist, SDK IL build)
  • Port control plane (attestation, approval, pointer CAS, quiesce/promote)
  • Port quarantine runner against product brain, not POC RunStore
  • Either rewrite DigitalBrain.Scripting as external worker client or delete it
  • Gate: CORE-DESIGN §10 acceptance items that matter productized (restart, grants, refuse, chart projection)

Phase 5 — First vertical + retire dual runtime

chart sample module · product proof · delete POC from default path
  • Trusted chart contracts + ChartNeuron as product sample module
  • End-to-end: admit candidate → cold restart → SocialPostObserved → Flutter/projection
  • Keep poc/ only until product gates supersede every required proof
  • Stop indexing Prototypes for agents (workspace / codegraph scope) when ready
