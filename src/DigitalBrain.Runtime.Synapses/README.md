# DigitalBrain.Runtime.Synapses

Compiles synapse source (`SynapseSource`: a key and its C# files) into an assembly and a portable PDB with `SynapseCompiler`. The source compiles against `ReferenceSet.FromDefaultContext()` (the assemblies of the default load context plus the trusted platform assemblies, closed by their references) with the framework's global usings, and every shipped DigitalBrain analyzer plus the synapse shape rule (DB0041) runs over it; any error fails the build with file, id, line and message. Successful builds are cached by a hash over the sources and the reference fingerprint.
