# Google sign-in button asset

`google-signin-light-2x.png` is the unchanged official light pill Google
sign-in asset from Google's `signin-assets.zip` download:

- Source: <https://developers.google.com/static/identity/images/signin-assets.zip>
- Branding guidance: <https://developers.google.com/identity/branding-guidelines>
- Archive path: `Android + Web/PNG @2x/Light/Theme=Light, Show text=Yes, Shape=Pill, Platform=Android+Web@2x.png`
- SHA-256: `86C7955EE72F3635DC4E1415AC6E10035CA0BB1319245C8E1B441CE1CB5F6981`

The Flutter card displays the 360 x 80 image at 180 x 40 without recreating
Google's icon, text, typography, or button treatment.
