# DigitalBrain v2 — Slice 4: The Edge — UiGateway + Catalog

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Checkbox steps.

**Goal:** `edge/Brain.UiGateway` — the UI transport decided in spec v2 §7.2: `POST /ui/invoke`, `GET /ui/read`, `GET /ui/describe`, and `WS /ui/watch?cursor=N` streaming feed records from a durable cursor — plus a kind catalog that is itself a neuron (`catalog/{id}`), served by the existing `neuron_read`. Proven live: HTTP invoke posts to chat → the open WebSocket delivers the feed record; catalog readable via MCP with zero new tools.

**Architecture:** The gateway is a dumb pipe: authenticate (dev identity this slice), forward envelopes, stream the feed. Watch = server-side loop on `INeuron.ReadEventsAsync(feed/main, cursor)` (~700ms poll) pushing each `feed.record` event as one JSON text frame `{sequence, sourceKey, revision, kind}`; reconnect = reopen with last sequence. Catalog: `AddBrainKernel`/`AddBrainKind` append `(kind, contracts)` into a `KindCatalog` singleton; a kernel-built-in `CatalogKind` projects it. No protobuf, no codegen, no new runtime.

**Rescope note:** Google/Salesforce move to Slice 5 (OAuth port + conformance); behaviors → Slice 6; app → Slice 7; demolition → Slice 8. Feed one-way-append and journal compaction remain carried (watch works on the awaited append).

### Task 2: Brain.UiGateway (commit 2)

- `edge/Brain.UiGateway/Brain.UiGateway.csproj` (Web SDK; refs Brain.Client, Brain.Contracts, ServiceDefaults), `Program.cs`, `Properties/launchSettings.json` (http, `http://localhost:5320`).
- Program (minimal API, mirrors Brain.Mcp bootstrapping: `AddBrainClient()` + `AddServiceDefaults()` + `UseWebSockets()`):
  - `POST /ui/invoke` body `{address, contract, inputJson, commandId, expectedRevision?}` → `INeuron.InvokeAsync` with caller `local-owner|actor/ui-dev|session/dev`; `BrainException` → 409 JSON `{code, detail}`; success → receipt JSON.
  - `GET /ui/read?address=&projection=` → snapshot JSON. `GET /ui/describe?address=` → description JSON.
  - `Map("/ui/watch")`: accept WS; query `cursor` (default 0) + `space` (default `actor/ui-dev`); loop until socket closed: `ReadEventsAsync(cursor, 100)` on `local-owner|{space}|feed/main`; for each event of kind `feed.record` send one text frame `{"sequence":revision,"record":<payload>}`; advance cursor to `NextRevision`; when empty, `Task.Delay(700, aborted)`; heartbeat frame `{"ping":true}` every 15s idle. Wrap loop in try/catch → close socket gracefully.
- Tests `tests/Brain.KernelTests/UiGatewayTests.cs`: factor the endpoint handlers into a public static class `UiEndpoints` (methods taking `IClusterClient` + primitives) so handlers are unit-testable against the TestCluster client without booting Kestrel: invoke-happy-path (chat post → receipt), invoke-conflict (`BrainException` mapped to `{code}` payload — test the mapping helper), read + describe pass-through, watch-page mapper (feed events → frames, cursor advance) as a pure function `WatchPager.NextFrames(NeuronEventPage)`. WS loop itself is live-proof territory.
- AppHost additive: `builder.AddProject<Projects.Brain_UiGateway>("brain-ui").WithHttpEndpoint(port: 5320).WaitFor(brainKernel);` — mirror brain-mcp lines; also add the csproj ItemGroup entry.
