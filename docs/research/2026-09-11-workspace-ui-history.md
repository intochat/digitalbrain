## Chat package and composer: reusable without turn orchestration

The old full chat already used **KitChat**, which wraps `Chat` from `flutter_chat_ui` with `flutter_chat_core.ChatController`. Its contract explicitly leaves transport/conversations to the host. It selects a light/dark chat theme from `Theme.of(context)` and decorates builders with copy support. [kit_chat.dart](E:/intochat/digitalbrain/src/Modules/UI/Flutter/kit/lib/src/chat/kit_chat.dart):1,8,31.

`BrainChatScreen` owned an `InMemoryChatController`, stream-state store, recorder, pending sends and journal synchronization. Its `part 'brain_chat_presentation.dart'` owns presentation; that part invokes KitChat at line 40, a custom composer at line 62, FlyerChat text at line 73, streaming text at line 86, and `KitChatBuilders.customMessageBuilder` at line 102. Those custom builders accept typed chart/image/spreadsheet/graph readers. [brain_chat_screen.dart](E:/intochat/digitalbrain/src/Modules/UI/Flutter/shell/lib/chat/brain_chat_screen.dart):1,21,97; [brain_chat_presentation.dart](E:/intochat/digitalbrain/src/Modules/UI/Flutter/shell/lib/chat/brain_chat_presentation.dart):40.

The composer has a preserved draft/focus controller, multiline text field, Enter shortcut, attach callback, send button, conditional voice recording button, and horizontal prompt shortcuts. Attachment is only a callback and the historical entry point did not supply one, so this is not evidence of finished upload support. Voice was wired by the entry point to `sendVoice`; recorder/voice-file helpers lived in the screen. Prompt shortcuts mention behaviors/code review and should be replaced for the simplified product. [brain_chat_composer.dart](E:/intochat/digitalbrain/src/Modules/UI/Flutter/shell/lib/chat/brain_chat_composer.dart):8,40,102.

**Reuse recommendation:** retain KitChat, themed text/stream renderers, copy affordances, composer visual/control patterns and custom artifact builders. Feed them AG-UI messages/tool results with a new transport adapter. Keep the current persistent table controller/card behind a custom message builder. Do not restore `WorkspaceSession`, `_syncJournal`, turn/correlation pending-send bookkeeping or graph subscriptions merely to recover the chat appearance. These are separable UI and transport concerns, supported by KitChat's existing interface.
